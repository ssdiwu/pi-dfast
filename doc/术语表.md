# pi-dfast 术语表

**Fast Mode（快速模式）**：
用户显式开启后，请求符合资格的 Codex 模型使用 Priority Service Tier（优先服务等级）的运行状态。

**active（活动）**：
Fast Mode 已开启，并且当前 provider（提供方）与 model（模型）满足本地请求注入条件。它不是服务端生效证明。

**DFastSnapshot（快速模式快照）**：
`pi-dfast` 通过事件总线发布的版本化公开状态，不包含认证信息或请求内容。

**Session state（会话状态）**：
记录在当前 Pi session 中、只随该会话及其当前分支恢复的 Fast Mode 开关；它不是全局或项目默认值。
